### 평가지표

최적화 방향은 클수록 좋다.

```text
Score = 0.9 × ADS + 0.1 × CPS
ADS   = 0.5 × (1 - File EER)
      + 0.2 × (1 - Voice EER)
      + 0.3 × (1 - Music EER)
CPS   = 0.5 × Voice Presence ROC-AUC
      + 0.5 × Music Presence ROC-AUC
```

FAKE가 양성 클래스 1이다. Voice EER은 음성이 존재하는 샘플에서만, Music EER은 음악이 존재하는 샘플에서만 계산한다. 공식 EER 구현은 `roc_curve(..., drop_intermediate=False)`에서 FPR과 FNR 차이가 가장 작은 지점을 고른 뒤 두 값을 평균한다. 로컬 검증은 이 이산 구현을 그대로 고정해야 한다.

Public Score는 전체 테스트 데이터 100%로 계산되고 Private Score는 대회 종료 시점의 Public Score라고 명시되어 있다. 별도 비공개 비율 분할이 없으므로 리더보드 반복 제출을 검증셋처럼 사용하는 행위는 특히 위험하다.

- 라이선스·출처·생성 계보가 없는 데이터를 학습에 사용
- 조건부 대상이 존재하지 않는 샘플을 Voice/Music EER 학습·평가에 무조건 포함

## 9. 도메인 지식 조사와 근거 수준

도메인 조사 전문은 `domain-research.md`, 외부 주장과 데이터 검사의 연결은 `evidence-map.csv`에 있다. 핵심은 음성 딥페이크 탐지의 성능이 생성기, 원천 데이터셋, 코덱·채널, 실제 음성 다양성의 변화에 크게 흔들릴 수 있다는 점이다. 이 대회는 음악과 혼합 오디오까지 포함하므로 음성 전용 문헌 결과를 음악에 그대로 일반화해서는 안 된다.

## 10. 외부 주장과 실제 데이터 검사 대응

현재 실제 결과는 모두 `NOT_TESTED_DATA_MISSING`이다. 문헌 주장은 모델 아이디어가 아니라 검사 설계로만 전환했다.

| 문헌상 위험 | 이 데이터에서 할 검사 | 현재 결과 |
|---|---|---|
| 원천 데이터셋 변화에 대한 일반화 저하 | 출처 전체 홀드아웃 | 원본 없음 |
| 생성기 차이가 성능 격차의 주원인일 수 있음 | 생성기 전체 홀드아웃 | 원본 없음 |
| 코덱·전송 조건 영향 | 포맷·비트레이트·전화채널 층화 | 원본 없음 |
| 실제 음성 다양성 부족이 EER를 낙관시킬 수 있음 | 환경·화자·발화 스타일별 REAL 교차 테스트 | 원본 없음 |
| 신경 코덱 기반 생성물은 기존 보코더 흔적과 다를 수 있음 | 생성 방식 계열별 홀드아웃 | 원본 없음 |

## 11. 데이터에서 도출된 제약과 검증 가능한 가설

### 확정 제약

- 파일별 독립 추론을 코드 수준에서 강제한다.
- 모든 입력 형식과 16 kHz 모노/스테레오를 처리하되, 채널 축을 임의로 버리는 전처리의 영향을 그룹별로 검증한다.
- 4~60초 전체를 파일 단위로 집계하며 세그먼트는 같은 폴드를 유지한다.
- 5개 출력은 유한한 0~1 값이어야 하고 ID·행 순서를 샘플 제출과 일치시켜야 한다.
- 외부 자원은 사용 전에 출처, 버전, 라이선스, 다운로드 시각, SHA-256, 재배포·비영리 사용 조건을 등록한다.

### 데이터 확보 후 검증할 가설

- 전화채널·손실 압축 조건에서 음성 FAKE EER가 악화될 수 있다.
- 학습에 포함되지 않은 생성기·원천 데이터셋에서 EER가 크게 악화될 수 있다.
- 혼합 오디오는 성분 존재 판별과 조건부 FAKE 판별 모두에서 단일 성분보다 어렵다.
- 후처리된 REAL이 깨끗한 REAL보다 FAKE로 오인될 수 있다.

위 가설은 현재 데이터로 검증되지 않았으므로 모델 선택 근거로 확정해서는 안 된다.

## 12. 최종 게이트

### 확인한 사실

- 공식 문제·출력 5개·평가 산식·최적화 방향·조건부 EER 범위·실행 환경·주요 규칙을 공식 페이지에서 확인했다.
- 공식 학습 데이터가 제공되지 않고 평가 입력 형식용 더미 3개만 배포된다는 점을 확인했다.
- 실제 저장소와 `deepvoice` 코드는 존재한다.
- 요구 원본 디렉터리와 외부 학습 데이터 등록은 존재하지 않는다.

### 아직 확인하지 못한 사항

- `open.zip`의 파일 크기, SHA-256, 압축 무결성, 실제 내부 경로
- 더미 오디오 3개의 메타데이터·품질·내용
- 실제 `sample_submission.csv`의 정확한 바이트·헤더·ID
- 사용할 학습 데이터의 스키마·분포·라이선스·중복·누수
- 공식 공지·FAQ·토크의 이후 규칙 개정 여부
- 공식 데이터 다운로드 버튼의 인증·참가 동의 요구 조건과 직접 파일 URL
- 감사 이후 게시될 공지·FAQ·규칙 개정

### 치명적 위험

- 학습 데이터가 없어 모델링의 통계적 근거와 재현 가능한 검증셋이 전혀 없다.
- 공개 평가 데이터 전체가 리더보드에 노출되는 구조여서 반복 제출 과적합 위험이 높다.
- 파일별 독립 예측 규칙을 위반하는 배치 정규화·테스트 통계 보정은 실격 위험이 있다.
- 외부 학습 자원의 라이선스·출처를 사후에 복원하지 못하면 2차 평가 검증을 통과하기 어렵다.
- 최종 학습에 사용한 실제 데이터 파일과 생성·재현 자료를 모두 보존하지 않으면 2차 평가 제출 요건을 충족할 수 없다.

### 사용자에게 필요한 최소 조치

1. 데이콘에 로그인하고 대회 참가·동의 절차를 완료한다.
2. 공식 데이터 탭에서 `open.zip`을 직접 다운로드한다.
3. 원본 그대로 `C:\Users\MY PC\Desktop\Hackathon\data\raw\deepvoice\official-2026-08-30\open.zip`에 둔다. 압축을 풀더라도 원본 ZIP을 덮어쓰지 않는다.
4. 학습에 사용할 공개 음성·음악 REAL/FAKE 데이터 후보의 URL과 라이선스를 `deepvoice/docs/DATA_SOURCES.csv`에 등록하고 파일을 별도 버전 디렉터리에 둔다. 생성 데이터는 생성 스크립트, 모델·버전·리비전, 시드, 프롬프트, 후처리 파라미터와 실제 생성 파일을 모두 보존한다.
5. 감사 스크립트를 실행한 뒤 전체 데이터 감사를 다시 요청한다.
